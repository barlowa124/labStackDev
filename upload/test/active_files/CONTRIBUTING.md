# Contributing

Thanks for contributing.

## License

By contributing code, you agree your contribution is licensed under `Apache-2.0`.

## Data safety requirements

Before opening a PR, confirm:

- No restricted or unclassified lab data is included
- No secrets/tokens/credentials are committed
- Any included dataset artifacts are clearly labeled with classification

If a dataset is not explicitly approved for public release, do not commit it.

## Practical checks before PR

- Run local smoke tests for changed workflows
- Confirm UI changes include user-facing guidance/tooltips where needed
- Keep outputs and logs out of commits unless intentionally included as synthetic examples
