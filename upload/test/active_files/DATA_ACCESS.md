# Data Access and Sharing

## Repository licensing model

- Code in this repository: `Apache-2.0` (`LICENSE`)
- Documentation: share under `CC BY 4.0` where explicitly marked
- Data: governed by classification and approval, not automatically open

## Access model for non-public data

Non-public datasets are shared through controlled channels, not committed to the public repository.

Required before access is granted:

1. PI or lab owner approval
2. Confirmation of compliance requirements (IRB/HIPAA/FERPA/sponsor terms/export control as applicable)
3. Minimal-access principle (only what is required for the task)
4. Audit trail of who received what data and when

## Public release checklist for datasets

Before releasing any dataset publicly, verify:

- De-identification has been completed and documented
- Sponsor/partner terms allow release
- No protected data classes remain
- Approval is recorded (PI and/or compliance office as required)
- Dataset is labeled `PUBLIC` in accordance with `DATA_CLASSIFICATION.md`

## Contributor rule

Do not commit raw lab data unless it is explicitly labeled `PUBLIC` and approved for release.
When uncertain, open an issue and request a data classification review first.
